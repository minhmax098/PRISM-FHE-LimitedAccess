Threshold FHE (t-out-of-n)

PRISM utilizes a Threshold Fully Homomorphic Encryption scheme based on BFV-RNS. No single institution or central server holds the complete secret key.

  • Joint Public Key ($PK_{joint}$): Used by hospitals to encrypt local VCF genotype files.
  • Secret Key Shares ($SK_i$): Distributed across Key Management Committee members.
  • Decryption Quorum: At least $t$ out of $n$ committee members must produce partial decryptions to reveal candidate causal variants.
Inheritance Models Supported

PRISM defines specific homomorphic logic for Mendelian inheritance patterns:

  • Recessive Model: Affected individuals have $g=2$ (homozygous mutation), parents are carriers ($g=1$).
  • Dominant Model: Affected individuals carry at least one mutant allele ($g \ge 1$).
  • De Novo Model: Affected children carry mutations absent in unaffected family members.
Multi-Hospital Encrypted Data Pipeline
1. Local VCF Encoding

Hospitals convert VCF genotypes into binary SIMD vectors locally.

2. Cloud Pooling

Encrypted ciphertexts are uploaded to a single cloud server.

3. ADD-IN Filtering

Cloud evaluates homomorphic sums & random blinding in constant depth.

4. Collective Decrypt

Committee fuses partial decryptions to reveal causal variants.
